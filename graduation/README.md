# YOLOv11 vs YOLOv8: 재활용품 객체 탐지 성능 비교 연구

## 1. 프로젝트 개요

### 1.1. 연구 목표
본 프로젝트의 목적은 폐기물 관리 및 재활용 자동화의 중요성이 대두됨에 따라, 최신 딥러닝 객체 탐지 모델인 **YOLOv11**과 **YOLOv8**의 성능을 '재활용품 탐지'라는 특정 도메인에서 정량적으로 비교 분석하는 것입니다.

이 연구는 "최신 YOLOv11 아키텍처는 이전 세대인 YOLOv8에 비해 실제로 더 효율적(더 가볍고, 더 빠르며, 더 정확한가)인가?"라는 핵심 질문에 답하고자 합니다.

### 1.2. 비교 대상 모델
본 연구에서는 두 모델의 크기(Nano, Small, Medium)별 성능을 모두 비교하기 위해 총 6개의 모델을 실험 대상으로 선정했습니다.
* **YOLOv11 계열:** `yolov11n`, `yolov11s`, `yolov11m`
* **YOLOv8 계열:** `yolov8n`, `yolov8s`, `yolov8m`

### 1.3. 사용 데이터셋
* **데이터:** TACO dataset
* **클래스:** `Bottle`, `Can`, `Paper`, `Plastic bag`, `Cigarette`, `Bottle cap` 등 18개 이상의 다양한 재활용품 및 쓰레기 클래스 포함.
* **데이터 분할:** Train (70%), Valid (20%), Test (10%) 비율로 분할하여 사용.

## 2. 사용된 도구 및 핵심 스크립트

* **핵심 기술:** `Python 3.10`, `PyTorch`, `Ultralytics YOLO`
* **분석 도구:** `Seaborn`, `Matplotlib`, `Pandas`
* **주요 스크립트:**
    * `train_yolo.py`: YOLO 모델(v8, v11)을 학습시키기 위한 메인 스크립트.
    * `predict.py`: 학습된 `best.pt` 모델을 로드하여 새로운 이미지에 대한 추론(예측)을 수행하고 결과를 저장하는 스크립트.
    * `generate_graph.py`: 6개 모델의 실험 결과를 바탕으로 '정확도-효율성' 비교 그래프를 생성하는 스크립트.

## 4. 결론 및 고찰

* **Nano(n) 및 Small(s) 모델**에서는 YOLOv11이 YOLOv8 대비 더 적은 자원(파라미터, GFLOPs)을 사용함에도 불구하고 더 높은 정확도(mAP)를 달성했습니다. 이는 경량 모델에서의 아키텍처 효율성이 크게 개선되었음을 시사합니다.
* **Medium(m) 모델**에서는 YOLOv8m이 근소하게 더 높은 정확도를 보였으나, YOLOv11m은 훨씬 적은 파라미터(-22.5%)와 연산량(-14.0%)을 사용했습니다. 이는 실제 시스템 배포 시, 약간의 정확도를 희생하는 대신 더 빠른 속도와 가벼운 모델을 선택할 수 있는 유의미한 트레이드오프 관계를 제공합니다.
* 본 연구를 통해 YOLOv11은 재활용품 탐지와 같은 실제 산업 현장에 적용하기에 매우 효율적이고 강력한 모델 후보임을 실험적으로 입증하였습니다.
